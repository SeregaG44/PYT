# 🛒 Консольний кошик покупок (Shopping Cart Console App)

Простий консольний застосунок на мові **Python**, який імітує роботу кошика інтернет-магазину. Проєкт розроблено в освітніх цілях для закріплення базових навичок програмування.

---

## 🚀 Можливості програми
1. **Додавання товарів:** Можливість обрати товар з каталогу, автоматично розрахувати загальну суму покупки та зберегти назви обраних товарів.
2. **Перегляд кошика:** Вивід списку замовлених товарів та поточної загальної суми чека.
3. **Очищення кошика:** Сброс поточної суми та списку товарів до початкового стану.
4. **Вихід із програми:** Завершення роботи циклу магазину.

---

## 🏷️ Каталог товарів та ціни
* **Подушка** — 650 грн
* **Ковдра** — 1700 грн
* **Лампа** — 500 грн
* **Брелок** — 60 грн

## 🛠️ Використовувані технології
* **Python 3.x**
* Базові конструкції керування потоком (`while True`, `if / elif / else`)
* Робота зі змінними, рядками та операторами присвоєння (`+=`)
